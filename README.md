## 📋 LICENSE के बारे में

**Eclipse Public License (EPL) v2.0** एक **open-source license** है जो:

✅ **फायदे:**
- लोग आपके code को **use, modify, और distribute** कर सकते हैं
- **Commercial use** की अनुमति है
- आपके **intellectual property** सुरक्षित रहते हैं

⚠️ **शर्तें:**
1. **Source code** को available रखना पड़ेगा
2. Changes को **document** करना पड़ेगा
3. LICENSE file को हर **copy के साथ** include करना पड़ेगा
4. अगर कोई **patent claim** करे तो उसका rights terminate हो जाएगा
